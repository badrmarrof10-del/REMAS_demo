# REMAS Home Collection — React V4

نسخة React + Vite بتصميم Portfolio فاخر، والوضع المظلم هو الوضع الافتراضي.

## التشغيل

1. ثبّت Node.js (الإصدار 20 أو أحدث مفضل).
2. افتح Terminal داخل مجلد المشروع.
3. نفّذ:

```bash
npm install
npm run dev
```

4. افتح الرابط الذي يظهر لك، غالبًا:
`http://localhost:5173`

## Production

```bash
npm run build
npm run preview
```

## المظهر

- Dark Mode افتراضي.
- زر الشمس/القمر أسفل يسار الشاشة لتبديل الوضع.
- الاختيار محفوظ تلقائيًا في المتصفح.

## ملاحظات

- صور المنتجات الحالية مرتبطة بمصادر الكتالوج المستخدمة في النسخة السابقة.
- نموذج الاستفسارات يحفظ آخر طلب في localStorage في هذه النسخة التجريبية؛ ربط قاعدة بيانات حقيقي يكون في مرحلة الإنتاج.
- ملفات GLB/USDZ الحقيقية يمكن وضعها لاحقًا لتفعيل AR/VR الحقيقي.
